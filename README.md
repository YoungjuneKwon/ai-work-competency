# AI 업무 활용 능력 테스트

**Second Tiger**

내가 쓰는 AI와 함께 가상의 기업 업무를 수행하며, AI 활용 능력을 확인하는 자가평가 스킬입니다. 스킬이 새로운 업무 상황과 분석 자료를 만들고, 여러분이 AI에게 내리는 지시와 결과를 검토·개선하는 과정을 평가합니다.

평가 문제는 기획, 상황 분석, 업무보고 등으로 구성됩니다. 외부 자료 조사 또는 제공된 내부 자료 분석을 거쳐야 해결할 수 있습니다. 기본 제한 시간은 **과제당 15분**입니다.

## 복사해서 시작하기

> v0.2 초안입니다. 실제 AI 서비스별 동작과 채점 일관성은 시험 중입니다.

아래 프롬프트를 복사해 평소 사용하는 AI 서비스의 **새 대화**에 붙여넣으세요. 스킬 설치 기능이나 웹 접근 가능 여부에 따라 AI가 진행 방법을 안내합니다.

```text
Second Tiger의 AI 업무 활용 능력 자가평가 스킬을 불러와 실제 테스트를 시작해 주세요.

저장소: https://github.com/YoungjuneKwon/ai-work-competency
스킬 위치: skills/ai-work-competency/

1. 이 저장소의 아래 파일 원문을 읽어 주세요. README나 검색 결과 요약만으로 스킬 내용을 추측하지 마세요.
   - skills/ai-work-competency/SKILL.md
   - skills/ai-work-competency/references/rubric.md
   - skills/ai-work-competency/references/scenario-generation.md
2. 현재 서비스가 사용자 스킬 설치를 지원하고 설치 권한이 있다면, 현재 서비스의 정식 설치 방식에 따라 위 스킬과 참조 파일을 설치해 주세요. 설치 경로나 방법을 모르면 성공했다고 말하지 말고 필요한 절차를 알려 주세요. 설치가 지원되지 않으면 읽은 파일을 이 대화의 평가 진행 지침으로 적용해 주세요. 어느 방식인지 먼저 알려 주세요.
3. 웹이나 파일에 접근할 수 없으면 필요한 파일을 제가 첨부하거나 붙여넣도록 요청해 주세요. 파일을 실제로 읽기 전에는 평가를 시작하지 마세요.
4. 스킬을 불러온 뒤 기업의 기획·상황 분석·업무보고 중 하나를 주제로 표준 난이도의 새 평가 문제를 만들어 주세요. 분야는 가상의 중소기업으로 해 주세요. 외부 자료 조사 또는 복수 내부 자료 분석이 반드시 필요해야 합니다. 웹 검색 기능이 없으면 합성 내부 자료 분석형으로 진행해 주세요.
5. 평가용 상황과 실제 분석에 사용할 자료 묶음, 제약 조건, 요구 산출물을 제시해 주세요. 자료는 대화에서 읽을 수 있는 표와 메모로 제공해 주세요. 문제를 낸 직후 정답이나 완성 보고서를 대신 작성하지 말고, 제가 첫 업무 지시를 내릴 때까지 기다려 주세요.
6. 이후에는 제 지시에 따라 업무를 도와주되, 제가 한 지시·검토·판단과 AI가 스스로 한 일을 구분해 기록해 주세요. 도움말을 요청하면 도움받은 수행으로 표시해 주세요. 중간 조건 변경도 스킬 지침대로 제시해 주세요.
7. 문제 제시 응답 맨 위에 스킬이 지정하는 Second Tiger 공식 인장 이미지를 표시해 주세요. 이미지 표시를 지원하지 않으면 그 사실과 원본 이미지 링크를 알려 주세요.
8. 과제 제한 시간은 15분입니다. 문제와 자료의 맨 끝에 시작·마감 시각, 제한 시간, '평가해줘' 또는 '평가 실시'라고 입력하면 조기 종료·평가한다는 안내를 적어 주세요. 정확한 시각 조회가 가능하면 매 응답에 제한 시간 대비 남은 시간을 표시하고, 마감 이후 입력에는 추가 작업 없이 즉시 종료·평가해 주세요. 시각 조회가 불가능하면 시간을 추측하지 말고 사용자 타이머 방식과 그 한계를 안내해 주세요.
9. 제가 '평가해줘', '평가 실시', '최종 제출, 채점해 주세요'라고 하거나 제한 시간이 만료되면 5개 영역, 총 25개 세부 항목을 각각 0~5점으로 평가하고, 기존 가중치를 적용한 100점 총점과 근거별 피드백을 제시해 주세요. 관찰하지 못한 항목이 있으면 임의로 점수를 채우지 말고 평가 미완료로 표시해 주세요.

먼저 스킬을 읽고 적용한 방식과 평가 기준을 짧게 안내한 다음, 첫 문제와 자료를 제시해 주세요.
```

서비스에 따라 사용자 스킬 설치와 웹·파일 접근 기능이 다릅니다. 이 프롬프트는 지원되지 않는 설치 기능을 새로 만들지 않습니다. 대화 내 적용은 새 대화에서도 유지되는 영구 설치와 다릅니다.

## 어떻게 평가하나요?

| 영역 | 세부 항목 수 | 세부 항목 배점 | 가중 만점 |
|---|---:|---:|---:|
| 문제 정의 | 5개 | 각각 0~5점 | 20점 |
| 지시 설계 | 5개 | 각각 0~5점 | 20점 |
| 맥락 유지·연계 | 5개 | 각각 0~5점 | 25점 |
| 검증·비판적 평가 | 5개 | 각각 0~5점 | 25점 |
| 윤리·제어 권한 | 5개 | 각각 0~5점 | 10점 |

원점수는 125점이며, 영역별 가중치를 적용한 총점은 100점입니다. 세부 기준은 [평가표](skills/ai-work-competency/references/rubric.md)에 공개되어 있습니다. 특정 프롬프트 문구를 외워 쓰는 대신 실제 업무 수행 행동을 평가합니다.

## 반복 테스트와 삭제

설치·삭제를 반복할 수 있습니다. 단, 삭제해도 기존 대화에 이미 불러온 지침이나 평가 기록까지 지워지는 것은 아니므로 매번 새 대화에서 시험하세요. 설치 여부 검증과 출제·채점 검증은 구분하고, 비교할 때는 같은 스킬 버전·모델·난이도·자료 모드를 기록하세요.

영구 설치 기능이 없는 서비스에서 대화 내 지침으로만 적용했다면 새 대화에서 다시 시작하면 됩니다. 영구 설치했다면 해당 서비스의 스킬 관리 기능으로 삭제하세요. 스킬 자체는 별도 저장·외부 전송 기능을 제공하지 않지만 대화 기록 보관은 각 AI 서비스 설정을 따릅니다.

## 테스트 진행 예

1. 시작 프롬프트를 붙여넣습니다.
2. AI가 공식 인장, 새 업무 상황과 자료, 시작·마감 시각 및 15분 제한 안내를 제공합니다.
3. 여러분이 업무 지시를 내리고 결과를 검토하며 과제를 수행합니다.
4. 중간 조건 변경을 반영해 최종 보고를 완성합니다.
5. 제한 시간 전에도 `평가해줘` 또는 `평가 실시`라고 입력하면 종료·평가합니다. 시간이 지난 뒤 입력하면 추가 작업 없이 종료·평가합니다.

정확한 시각 조회가 가능한 AI는 매 응답에 확인 시각 기준 남은 시간을 표시합니다. 일반 채팅에서는 입력 없이 먼저 종료 알림을 보내지는 못하므로 다음 입력 시 만료를 판정합니다. AI 응답·도구 실행 대기 시간도 제한 시간에 포함됩니다. 시각 조회가 불가능한 서비스에서는 시작 시각을 사용자에게 확인하고, 휴대폰 등으로 15분 타이머를 켠 뒤 만료 시 `시간 종료`라고 보내도록 안내합니다. 이 경우 남은 시간의 정확한 표시와 자동 만료 판정은 지원되지 않습니다.

연습 중 힌트를 요청할 수 있습니다. 결과에는 도움받은 수행 여부가 표시됩니다. 실제 고객 정보나 회사 비밀을 준비할 필요는 없습니다. 기본 과제 자료는 모두 가상입니다.

## 점수 해석

현재는 v0.2 초안입니다. 이번 과제에서 관찰된 AI 활용 행동을 돌아보기 위한 평가이며, 공인 자격이나 검증된 채용 평가를 뜻하지 않습니다. 모델·도구·문제 난이도가 달라지면 결과도 달라질 수 있습니다. 출제·업무 보조·채점을 같은 AI가 담당하는 방식의 한계도 있습니다.
