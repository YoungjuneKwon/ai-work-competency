# 평가 기준 v0.5

각 영역은 세부 항목 5개로 구성한다. **25개 항목의 실제 배점 합계가 100점**이다. 별도의 원점수 총합이나 가중 환산 점수를 만들지 않는다.

| 영역 | 항목 ID | 항목당 만점 | 영역 만점 |
|---|---|---:|---:|
| 문제 정의 | P1~P5 | 4점 | 20점 |
| 지시 설계 | I1~I5 | 4점 | 20점 |
| 맥락 유지·연계 | C1~C5 | 5점 | 25점 |
| 검증·비판적 평가 | V1~V5 | 5점 | 25점 |
| 윤리·제어 권한 | E1~E5 | 2점 | 10점 |
| 합계 | 25개 | | 100점 |

## 공통 수행 수준과 항목별 점수

| 수행 수준 | 관찰 기준 |
|---|---|
| 0 | 기회가 있었지만 해당 행동이 없거나, 목적에 명백히 어긋난 행동을 유지함 |
| 1 | 필요성을 언급했지만 구체적인 대상·조건·실행이 없음 |
| 2 | 구체적 지시나 시도는 있으나 중요한 조건이 빠지거나 실행 확인이 부족함 |
| 3 | 기본 행동을 실행하고 업무에 적용했으나 일부 중요한 누락이 남음 |
| 4 | 핵심 조건을 충족하고 결과에 반영했으나 경미한 누락이 있음 |
| 5 | 아래 항목별 충족 기준을 실질적으로 달성하고 근거로 확인할 수 있음 |

짧은 지시도 기준을 충족하면 만점이다. 질문을 많이 하거나 여러 번 수정했다는 사실 자체로 가산하지 않는다. 같은 행동이 서로 다른 기준을 실제로 충족하면 복수 항목의 근거로 사용할 수 있으나, 각 기준을 충족한 이유를 따로 설명한다.

위 0~5는 행동의 충족 수준을 구분하는 기준이며 항목 점수가 아니다. 다음 표에서 해당 영역의 **실제 항목 점수**를 선택해 합산한다. 수행 수준을 별도 원점수로 합산·보고하지 않는다.

| 수행 수준 | P·I 항목(4점 만점) | C·V 항목(5점 만점) | E 항목(2점 만점) |
|---|---:|---:|---:|
| 0 | 0 | 0 | 0 |
| 1 | 0.8 | 1 | 0.4 |
| 2 | 1.6 | 2 | 0.8 |
| 3 | 2.4 | 3 | 1.2 |
| 4 | 3.2 | 4 | 1.6 |
| 5 | 4 | 5 | 2 |

실제 점수는 소수 첫째 자리까지 보존한다. 예: P1의 수행 수준이 3이면 P1은 2.4/4점이다. 아래 표의 만점 충족 기준은 수행 수준 5에 해당한다.

## 1. 문제 정의: 항목당 4점, 합계 20점

| ID | 세부 항목 | 만점 충족 기준 |
|---|---|---|
| P1 | 의사결정 목적과 독자 | 보고받는 사람, 내려야 할 결정, 그 결정에 필요한 정보를 업무 맥락에 맞게 정함 |
| P2 | 범위와 우선순위 | 분석 대상·기간·비교 범위와 제외 범위를 정하고 핵심 문제에 우선순위를 둠 |
| P3 | 제약과 성공 기준 | 예산·납기·인력 등 제약 및 채택·성공 판정 기준을 명시해 결과 판단에 사용함 |
| P4 | 필요한 근거 정의 | 내부 분석 또는 외부 조사에서 필요한 자료·지표·비교 대상을 정하고 확보 방식을 지시함 |
| P5 | 불명확성와 가정 관리 | 중요한 미확정 사항을 확인하거나 명시적 가정으로 처리하고 결론에 미치는 영향을 구분함 |

## 2. 지시 설계: 항목당 4점, 합계 20점

| ID | 세부 항목 | 만점 충족 기준 |
|---|---|---|
| I1 | 업무와 산출물 명세 | AI가 수행할 업무, 기대 산출물, 독자에 맞는 깊이·형식·분량을 구체화함 |
| I2 | 조사·분석 절차 설계 | 자료 확보·정리·분석·작성의 필요한 단계를 목적에 맞게 구성함 |
| I3 | 입력과 참조 지정 | 어떤 자료·열·기간·정의·템플릿을 사용할지 명확히 연결함 |
| I4 | 판단 기준과 비교 구조 | 대안 비교 기준·표 구조·계산 정의 등 결과의 판단 가능한 구조를 지정함 |
| I5 | 불확실성 처리 지시 | 자료 부족·충돌·추정치·도구 실패 시 확인 또는 표시할 방식을 지정함 |

역할 이름, “전문가처럼”, 톤, 예시 제공은 필요할 때만 도움이 되는 수단이다. 이를 형식적으로 넣었다고 가점하거나, 불필요한 역할·예시가 없다고 감점하지 않는다.

## 3. 맥락 유지·연계: 항목당 5점, 합계 25점

| ID | 세부 항목 | 만점 충족 기준 |
|---|---|---|
| C1 | 자료에서 분석으로 연결 | 조사·내부 자료의 확인 결과를 후속 분석의 입력으로 명시적으로 이어감 |
| C2 | 분석에서 보고로 연결 | 분석 결과·비교·산출 수치를 제안과 최종 보고의 근거로 재사용함 |
| C3 | 조건과 정의의 일관성 | 목적·기간·지표 정의·예산 등 주요 조건을 후속 단계에서도 일관되게 적용함 |
| C4 | 변경 사항의 전파 | 중간 조건 변경이나 자료 정정에 따라 관련 계산·비교·결론을 함께 갱신함 |
| C5 | 최종 산출물 통합 | 초안·보완·수정의 최신본을 일관된 최종 산출물로 통합하고 폐기된 가정과 섞지 않음 |

다단계 작업을 한 번에 구조화한 지시도 인정한다. 대화 횟수가 많아야 만점인 것은 아니다.

## 4. 검증·비판적 평가: 항목당 5점, 합계 25점

| ID | 세부 항목 | 만점 충족 기준 |
|---|---|---|
| V1 | 근거와 출처 검증 | 핵심 주장에 연결된 원자료·정의·시점·적용 범위를 확인함. 내부 모드에서는 자료 ID와 기준일을 검증함 |
| V2 | 수치와 논리 검산 | 핵심 계산·분모·단위·논리 연결을 재계산 또는 독립적인 비교로 점검함 |
| V3 | 충돌·누락·편향 탐지 | 자료 간 불일치나 결론을 왜곡할 수 있는 누락·표본 차이를 발견하고 처리함 |
| V4 | 대안과 한계 검토 | 다른 선택지·반대 근거·불확실성이 제안을 바꿀 가능성을 검토함 |
| V5 | 수정과 재확인 | 발견한 문제를 구체적으로 보완시키고 수정된 산출물에서 해결 여부를 확인함 |

“다시 확인해”라는 말만으로 검증 완료로 보지 않는다. AI가 원자료 대조·재계산을 실제 수행하도록 지시하고 사용자가 결과를 검토한 근거가 있으면 인정한다. AI가 처음부터 정확했다면 오류를 억지로 만들지 말고 기존 자료의 충돌 해결이나 반대 근거 검토로 관찰한다.

## 5. 윤리·제어 권한: 항목당 2점, 합계 10점

| ID | 세부 항목 | 만점 충족 기준 |
|---|---|---|
| E1 | 정보 최소화와 보호 | 제공된 합성 보안등급·개인정보 조건에 따라 외부 제공 범위를 정하고 비식별화·집계를 적용함 |
| E2 | 자료 이용 권한과 귀속 | 내부용·재배포 제한·외부 인용 자료의 이용 범위와 출처 표기를 확인해 산출물에 적용함 |
| E3 | 사실과 생성 내용 구분 | 확인 사실·추정·가정·AI 생성 내용을 구분하고 허위 출처나 미실행 조사를 사실처럼 쓰지 않음 |
| E4 | 실행 권한과 승인 | 초안 작성과 실제 발송·공개·구매를 구별하고 필요한 사람의 승인 지점을 설정함 |
| E5 | 인간의 최종 판단 | AI의 권고를 근거·한계에 비추어 검토하고 채택·보류 및 후속 확인의 책임 있는 결정을 제시함 |

문제에서 요구하지 않은 법률 지식을 시험하지 않는다. 모든 판단에 필요한 이용 제한과 승인 조건은 과제 자료에 제공한다. 가상 개인정보를 실제 비밀처럼 취급할 필요는 없지만, 가상 업무에서 어떤 처리가 적절한지의 사용자 판단은 평가한다.
