# 기업 업무 평가 문제 자동 생성 지침

## 1. 생성할 문제의 성격

일반 기업에서 발생할 법한 기획·현황 분석·의사결정·업무보고 과제를 창작한다. 전문 자격 지식이나 코딩 실력 대신 AI 활용 과정을 평가한다.

주제 예시: 신제품 시범 출시, 판매 부진 원인 분석, 고객 문의 운영 개선, 공급업체 비교, 사내 교육 도입, 채널별 마케팅 예산 배분, 경영진 월간 보고.

### 업무 분야별 출제 기준

SKILL.md의 선택 절차에서 확정한 업무 분야를 따른다. 아래는 출제 틀이며 고정 문제나 정답이 아니다. 해당 분야의 실질적 의사결정과 자료·지표를 새로 생성한다. 회사명·제목만 바꾸고 모든 분야에 동일한 판매 분석 문제를 내지 않는다.

| 분야 ID | 결정·산출물 예시 | 내부 자료 예시 | 외부 조사형의 조사 대상 | 검증·변경 기회 예시 |
|---|---|---|---|---|
| strategy | 신규 시장·서비스 2안 비교 후 경영진 제안 | 사업별 실적·고객 의견·시범운영 비용·전략 메모 | 지역별 인구·가구·산업별 사업체 통계 | 전체 시장과 목표 고객 범위 차이, 가용 예산 감액 |
| marketing-sales | 캠페인·판매 채널의 다음 달 예산안 | 광고비·문의·구매·반품·기여이익·영업 메모 | 연령별 인구·가계 소비지출·지역별 과거 기온과 강수량 | 매출과 순매출·전환 분모 차이, 채널별 집행 한도 변경 |
| finance | 비용 절감·투자·자금 배분안 보고 | 예산 대비 실적·고정/변동비·수금/지급 일정·설비 견적 | 물가·기준금리·환율의 공개 시계열 | 현금과 발생주의 이익·일회성 비용 차이, 수금 시점 변경 |
| operations | 재고·공급업체·문의 처리 운영 개선안 | 발주·납기·불량·재고·문의 유형·처리 시간·견적 | 지역별 과거 강수·기온·공공 물류·운송 통계 | 평균 처리시간과 상위 지연 구간 차이, 납기·인력 제약 변경 |
| people | 온보딩·교육·인력 배치 개선안 | 익명화 조직 설문·참여/완료 현황·가용 인원·교육 견적 | 지역·연령별 고용률·실업률·노동인구 통계 | 응답자와 전체 직원 분모 차이, 교육 예산·일정 변경 |

어느 분야든 공통 5영역 25항목과 기존 가중치를 유지한다. 분야별 전문지식 암기에는 점수를 주지 않는다. 낯선 용어·계산식은 자료에 정의한다. 인사 과제는 개인 채용·해고 판정을 요구하기보다 운영·집계 수준의 판단을 다루고, 재무 과제도 전문 세법·회계기준 해석보다 제공된 정의에 따른 분석으로 구성한다.

외부 조사 예시는 조사 범위일 뿐 실제 자료가 존재하거나 열람됐다는 뜻이 아니다. 외부 조사 모드에서는 원문을 직접 확인하고, 검색이 불가능하면 내부 자료 분석형 규칙을 따른다.

회사명·인물·내부 수치·사건은 가상으로 만들고 합성 자료임을 명시한다. 실제 기업의 비공개 정보인 것처럼 제시하지 않는다.

**모든 과제에는 아래 두 경로 중 적어도 하나가 필수다.** 자료 없이 상식만으로 기획안을 작성하는 문제는 출제하지 않는다.

- **내부 분석형:** 제공된 복수 내부 자료를 대조·계산·분석해야 결정을 내릴 수 있다.
- **외부 조사형:** 실제 외부 출처를 찾아 읽고 비교해야 결정을 내릴 수 있다.
- **혼합형:** 내부 현황과 외부 조사 결과를 함께 사용한다.

## 2. 표준 문제 설계표

문제를 제시하기 전에 다음 요소를 정한다. 해답·결함 위치를 사용자의 첫 과제 설명에 공개하지 않는다. 사용자가 출제 설계 자체를 검토해 달라고 하면 공개할 수 있다.

기본은 **15분 안에 수행 가능한 단일 과제**다. 의사결정 하나에 집중하고 자료 읽기는 약 2~3분을 목표로 압축한다. 평가 항목 25개를 독립 소과제 25개로 만들지 않는다. 실제 시간 내 수행 가능 여부는 시연으로 조정한다.

| 요소 | 표준 난이도 요구 |
|---|---|
| 업무 목적 | 의사결정 하나, 보고 독자 하나, 구체적인 납기와 산출물 |
| 대안 | 최소 2개, 비교 가능한 공통 기준과 상충하는 장단점 |
| 제약 | 예산·인력·시점 중 최소 2가지 |
| 내부 자료 | 내부·혼합형은 짧은 자료 3~4개, 수치 표 6~12행, 비교할 선택지나 기간 3개 이상 |
| 외부 근거 | 외부형은 독립된 출처 최소 2개를 직접 확인. 가능하면 공식·원자료 1개 이상 포함 |
| 수치 분석 | 자료 대조와 최소 2개 의미 있는 계산. 공식·분모·단위가 확인 가능해야 함 |
| 자료 충돌 | 기준일·분모·집계 범위·버전 중 하나가 다른 자료를 최소 1쌍 배치 |
| 불확실성 | 예측처럼 본질적으로 미확정인 조건 1개 이상. 필요한 기초 자료와 가정 범위·시나리오를 제공해 추가 문의 없이 판단 가능해야 함 |
| 조건 변경 | 중간에 예산·납기·요건·자료 정정 중 하나를 통보해 후속 결과 갱신 기회 제공 |
| 정보·권한 조건 | 합성 개인정보 또는 내부등급 정보, 자료 이용 제한, 실행 승인 규칙을 각각 제공 |
| 최종 산출물 | 결론·근거·대안·위험·실행안이 담긴 짧은 업무보고. 비교표 1개와 핵심 보고 5~8개 항목 수준 |

외부형이라도 예산·승인 조건 등을 담은 가상 내부 브리프는 제공한다. 공개 출처가 서로 모순된다고 조작하지 않는다. 내부 브리프에 비교 기간이 다른 잠정 수치를 넣는 등 투명하게 설명 가능한 차이를 설계한다.

## 3. 자료 묶음 생성

내부 분석형의 기본 구성:

1. **D1 업무 요청 메모:** 배경·독자·결정·납기·예산·승인 권한.
2. **D2 실적 표:** 기간·대안별 수치, 단위, 지표 정의, 합계 검산이 가능한 자료.
3. **D3 현장 의견·과거 보고:** 정량 결과와 대조할 정성 근거, 다른 기준일이나 집계 범위의 수치.
4. **D4 정책·자료 이용 메모:** 합성 개인식별자 또는 내부등급 정보의 취급, 외부 인용 범위, 발송·집행 승인 조건.
5. 필요하면 **D5 가정·시나리오 자료:** 미래의 추가 매출처럼 아직 확정할 수 없는 값은 합성 추정임을 명시한 저·중·고 시나리오, 추정 근거, 적용 범위를 처음부터 제공한다. 추가 가정이 필요 없으면 D5를 생략한다. “내부 부서에 요청하면 확인 가능”이라는 목록으로 대체하지 않는다.

각 자료에 ID, 작성일·기준일, 작성 부서, 공개 범위, 합성 여부를 붙인다. 표와 짧은 메모는 대화 안에 직접 제공해 첨부 도구가 없어도 시작할 수 있게 한다.

자료의 길이를 늘리기보다 교차 확인할 연결을 설계한다. 같은 지표가 등장하는 자료에는 대조 가능한 키를 둔다. 실적 표에서 출처 없는 정답을 찍는 대신, 자료 간 차이의 이유를 설명할 수 있게 한다.

### 가상 내부 정보의 완결성

- 문제 해결에 필요한 내부 사실은 처음부터 문제 자료 안에 제공한다. 가상 경영지원실·상사·거래처에 연락하거나 가상 회사명을 검색해야 얻을 수 있는 정보를 필수 조건으로 두지 않는다. 사용자에게 실제 사내 자료를 가져오라고 요구하지 않는다.
- 사용 가능한 인력 시간, 고객 불만 집계, 공급사 견적·납기 등은 가상의 구체적인 수치·표·메모로 제공한다. “확인할 수 있으나 결과 없음”은 자료로 보지 않는다.
- 미래 매출·수요 등은 확정 사실처럼 생성하지 않는다. 과거 실적·산정 규칙 또는 명시적인 시나리오 범위를 주어 추정·민감도 분석이 가능하게 한다. 특정한 숨은 추정값을 맞히게 하지 않는다.
- 불확실성 평가는 제공 자료의 한계를 인식하고 가정을 관리하는 행동으로 관찰한다. 존재하지 않는 부서에 연락하는 역할극이나 숨은 자료 요청을 필수 정답으로 삼지 않는다.
- 사용자가 추가 내부 사실을 물으면 제공 자료에서 답하거나 제공되지 않았음을 밝힌다. 이때 새로 꾸민 수치를 기존의 확정 사실처럼 추가하지 않는다. 출제 누락이라면 결함을 인정하고 보충·재출제와 시간 재설정을 사용자와 합의하며, 정보가 없어서 못 푼 점을 사용자 잘못으로 감점하지 않는다. 사전 설계한 중간 조건 변경은 별도 규칙대로 적용한다.

## 4. 외부 조사 조건

- **외부 검색 과제는 가상 기업의 존재 여부와 무관하게 공개 출처에서 반복 조회할 수 있는 객관적 지표 조사로 한정한다.** 날씨·기후 관측, 거시경제 지표, 인구·가구·고용·산업 통계 등이 대상이다. 공개 지표를 찾아 정의·시점·지역·단위를 검토하고 업무 판단에 연결하는 능력을 평가한다.
- “언제든 조사 가능”은 지표 값이 시간에 따라 변하지 않는다는 뜻이 아니다. 문제의 가상 날짜에만 존재하는 자료, 특정 날의 실시간 화면, 미래 예보나 미공표 미래 통계를 필수로 하지 않는다. 공개 아카이브에서 조회 가능한 완료 기간과 지역을 지정한다. 최신 자료가 필요하면 `조회 시점에 공개된 최신 확정치`처럼 기준을 정하고 실제 발표 시점을 기록한다.
- 가상 회사의 매출·고객·직원·인력 여력·판촉 효과·내부 결재 결과는 외부 검색 대상으로 삼지 않는다. 경쟁사 서비스 조건, 특정 업체 견적·SLA·교육상품 조건도 본 스킬의 외부 조사 필수 과제로 출제하지 않는다. 이런 조건이 필요하면 합성 내부 자료로 제공한다.
- 출제 시 공개 지표의 발표·조회 가능 여부를 확인한다. 통계청·중앙은행·기상기관 등 공식 공개 출처를 우선하며, 로그인·결제·실제 회사 소속 확인이 필요한 자료를 필수로 삼지 않는다. 실제 열람 확인을 못 했으면 확인했다고 주장하지 말고 내부 분석형으로 전환한다.
- 거시 지표나 인구통계로 특정 가상 회사의 성과를 확정할 수 있다고 주장하지 않는다. 지표의 업무 관련성과 적용 한계를 검토할 수 있도록 맥락을 제공하고, 무관한 검색 과정을 형식적으로 끼워 넣지 않는다.
- 조사 질문, 대상 지역·시장·시점, 필요한 정보의 범위를 정한다. 구체적인 검색 문구와 정답 출처를 미리 강제하지 않는다.
- 열람한 출처마다 제목·발행자·발행일(확인 불가 시 미상)·URL·접근일·뒷받침하는 주장을 기록한다.
- 존재하지 않는 URL, 꾸며낸 인용문·통계·발행일을 만들지 않는다. 검색 결과 요약만 봤으면 원문 열람처럼 쓰지 않는다.
- 검색이 불가능하면 시작 전에 내부 분석형으로 바꾸거나 사용자 제공 출처를 활용한다. 수행 중 장애라면 조건 변경 사실을 기록하고 부족한 관찰 기회를 보완한다.
- 최신성·지역·업종 차이를 검토할 여지를 둔다. 단순 링크 수집만으로 완료되는 과제를 만들지 않는다.

## 5. 출제 자체 점검

사용자에게 제시하기 전에 다음을 확인하고 실패하면 자료를 고친다.

1. **풀 수 있는가:** 핵심 계산의 정의와 내부 원자료가 처음부터 있으며, 미확정 조건은 제공된 가정·시나리오로 처리할 수 있는가? 가상 내부 부서에 추가 문의해야만 풀리는 부분을 없앴는가?
2. **자료를 실제로 써야 하는가:** 자료를 무시한 일반론으로는 요구 산출물을 충족할 수 없는가?
3. **25개 항목의 기회가 있는가:** rubric의 각 ID에 연결되는 과제 조건이나 자료를 하나 이상 매핑했는가? 정보·권한 판단도 관찰 가능한가?
4. **정합적인가:** 표 합계·단위·기간을 직접 검산했는가? 의도한 차이와 실수로 생긴 모순을 구별했는가?
5. **갱신할 내용이 있는가:** 조건 변경이 비교·계산·최종 제안 중 적어도 두 부분에 영향을 주는가?
6. **선결된 정답은 아닌가:** 복수의 합리적 권고가 가능하고, 특정 대안 선택보다 근거와 과정을 채점할 수 있는가?
7. **15분 안에 가능한가:** 읽기·분석·수정·조건 변경 대응이 시간 내 가능한가? 문제 맨 위에 공식 인장을 표시하고, 설명과 자료 맨 끝에 시작 시각·제한 시간·조기 평가 요청 및 만료 처리 안내를 붙였는가?
8. **외부 검색 가능한가:** 필수 검색 대상이 공개 객관 지표에 한정되며 지정한 지역·기간 자료가 실제로 발표되어 재조회 가능한가? 가상 기업 사실·미래 미공표 수치·특정 업체 내부 정보를 요구하지 않는가?

출제 시 핵심 계산의 참고값, 의도한 자료 차이의 해석, 허용 가능한 대안, 항목별 관찰 기회, 조건 변경 내용과 통보 시점을 정해 둔다. 수행 후 사용자에게 유리하거나 불리하도록 기준을 바꾸지 않는다. 별도 비공개 저장 기능이 없으면 정답이 안전하게 숨겨진다고 주장하지 않는다.

## 6. 조건 변경과 난이도

표준 변경 통보 시점은 **첫 분석 결과를 사용자에게 전달한 직후, 최종 제출 전**이다. 한 번의 지시로 최종 보고서까지 요청받았어도 이 지점에서 분석을 전달하고 변경 사실을 통보해 사용자의 후속 지시를 기다린다.

15분 과제에서는 한두 문장으로 변경을 통보한다. 시간 만료나 조기 평가 요청 처리가 조건 변경보다 우선한다. 종료 후 관찰 기회를 억지로 만들지 않는다.

조건 변경을 거절하거나 단축 평가를 원하면 요청을 따르되, C4 등 관찰 기회가 사라진 항목은 N/O로 표시한다.

- 입문: 자료량과 계산 복잡도를 줄이되 25개 관찰 기회를 유지한다.
- 표준: 위 설계표를 따른다.
- 심화: 이해관계자와 불확실성을 늘린다. 전문지식 암기나 반복 작업량으로 난이도를 올리지 않는다.

## 7. 출제 예시: 판매 부진 개선안

가상 생활용품 회사의 영업기획 담당자가 다음 분기 판촉 예산 배분안을 영업본부장에게 보고한다. 온라인몰·대리점·기업판매의 월별 매출·광고비·반품을 D2에 제공한다. D3에는 반품을 차감하지 않은 지난 보고서와 고객 불만 요약이 있어 두 자료의 실적을 그대로 비교할 수 없다.

사용자는 채널별 순매출과 판촉 효율을 비교하고, 예산 제약 안에서 최소 두 배분안을 검토해야 한다. D4는 고객 식별자가 있는 원문 의견의 외부 제공 제한과 실제 예산 집행 전 본부장 승인을 명시한다. 중간에는 예산 20% 감액을 통보한다.

이것은 출제 패턴 예시다. 실행 시에는 구체적인 회사 상황·수치·자료 묶음을 새로 생성하고 검산한 후 제공한다. 예시만 보여주고 평가 문제를 생성했다고 하지 않는다.
